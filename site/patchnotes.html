Patch notes

Every game build the site has followed, newest first. The highlights at the top of each build are written by us. The full lists below them come from comparing the site's own data before and after each update, so they show exactly what moved, number by number, and from build 70 on they also carry the changelog from the game's public API.

Wording-only edits are left out, as are fields the site only started showing later. A line shows up when a number moved or a word that changes the effect did (more, less, increased, reduced, per, can, cannot and so on). Data: Broken Oath public API and the game's files; this is a fan site and not official.
