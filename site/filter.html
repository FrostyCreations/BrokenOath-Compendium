Importing and exporting filters

What the game's filter can and can't check

  • Each rule can look at: item type (helm, chest, rune base and so on), rarity, item level, which kind of mod line it has, how good the rolls are, and how many good lines.
  • It can't tell base types apart, so there is no rule for "energy shield or armour/energy shield bases only". A chest rule covers every chest.
  • It can't count sockets. White rune bases with sockets always show in the Tidy preset and up, whatever the count.
  • Uniques, runes, idols, gems and currency always show.

Put a filter from this site into the game

  1. Make or open a filter here, then press Copy filter. The text starts with BOFILTER:.
  2. In game, open Settings (from inside the game with your hero loaded, not the main menu), then the Loot Filter tab.
  3. Press Paste filter. The game says how many rules it pasted.
  4. Each hero has its own filter, so do this once per character.

Bring your in-game filter here

  1. In game: Settings, Loot Filter, Copy filter.
  2. Here: Make a filter, then Paste a filter. Allow clipboard access if your browser asks, or paste into the text box under The filter as text.
  3. Edit any box, then copy it back into the game.

Share with friends

  1. Share it puts your filter in Shared filters with a name, so anyone can open or copy it.
  2. Or send the copied BOFILTER: text in Discord: your friend pastes it in game the same way.
  3. Only the browser that shared a filter can remove it.

If Paste filter doesn't work

  1. The game must be on a hero (Settings from the main menu has no filter).
  2. Make sure you copied the whole text, from BOFILTER: to the last number.
  3. Last resort: close the game, open %LOCALAPPDATA%\BrokenOath\Saved\Config\Windows\GameUserSettings.ini, find [BrokenOath.LootFilter], and replace everything after Hero_YourHeroID= with the part after BOFILTER:.

How the game reads a filter

  • Rules are checked top to bottom. The first rule an item fits decides, and anything no rule fits is shown.
  • Has a line checks the kind of mod (Lightning damage, Attack speed, Res and so on), not one exact mod.
  • Top roll means the line rolled its best tier (most need item level 84). Good roll means one of its two best. These are the lines a Vow takes.
  • 2+ lines and 3+ lines count how many lines pass the roll check.
  • Uniques, runes, Dwarven Runes, idols, gems and currency always show.
